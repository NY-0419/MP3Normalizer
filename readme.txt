音声一括ノーマライザー

このフォルダには、音声ファイルの音量を一括調整するWindowsアプリケーションが含まれています。

■ 起動方法

MP3Normalizer.exeをダブルクリックして起動してください。

MP3Normalizer.exeだけを移動・コピーせず、このフォルダ全体を保持してください。
_internalフォルダを削除するとアプリが起動できなくなります。

■ 対応形式

入力: MP3 / M4A (AAC / ALAC) / WAV / FLAC
出力: MP3 / M4A (AAC / ALAC) / WAV / FLAC

詳細設定の「入力形式に合わせる」を選択すると、入力ファイルと同じ形式で出力します。

■ 基本的な使い方

1. 「ファイル追加」で処理する音声ファイルを選択します。
2. 目標ラウドネスとトゥルーピークを設定します。
3. 出力先フォルダを指定します。
4. 必要に応じて詳細設定を変更します。
5. 「一括処理開始」を押します。

処理中は「処理キャンセル」で現在の処理を停止できます。

「音量を測定」で選択曲のラウドネス（LUFS）とトゥルーピーク（dBTP）を確認できます。

■ 注意事項

・出力形式を変更した場合、音声は再エンコードされます。
・M4A (ALAC)は可逆圧縮で出力されます。AACのようなビットレート指定は使用しません。
・目標ラウドネスは-70.0〜-5.0 LUFS、トゥルーピークは-9.0〜0.0 dBTPの範囲で指定できます。
・-5.0 LUFSと-9.0 dBTPは使用可能な境界値です。範囲外の値はFFmpegの仕様上使用できません。
・WAVは仕様上、アートワークを保持できません。
・極端に短い音源や無音に近い音源は、ラウドネス測定の精度が限定されます。
・「ファイル名を変更しない」設定では、出力先に元のファイル名（拡張子は出力形式に合わせる）で保存します。
・入力元と出力先が同じフォルダの場合は、元ファイルが上書きされる可能性があるため確認が表示されます。
・重要な音源は、処理前にバックアップを作成してください。
・Windows SmartScreenの警告が表示される場合があります。配布元を確認したうえで実行してください。

■ 設定とログ

設定とログは次の場所に保存されます。

%APPDATA%\MP3Normalizer\settings.json
%APPDATA%\MP3Normalizer\app.log

■ 同梱ソフトウェアについて

本製品にはFFmpegを同梱しています。
同梱FFmpegはLGPL v3で配布されるビルドです。

FFmpegのライセンス本文とビルド情報は、次のファイルを確認してください。

_internal\ffmpeg\LICENSE
_internal\ffmpeg\README.txt

FFmpegのソースコード情報は、同梱README.txtに記載されています。
FFmpegの著作権およびライセンスは、アプリ本体の権利とは別に扱われます。
